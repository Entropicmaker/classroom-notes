# DSH 本地课堂录音：上传即用

## 当前默认

使用 `classroom_audio` 原生工具，默认 `engine:"local"`：Apple MLX 上的 Qwen3-ASR-1.7B，加本地 ForcedAligner 时间戳模型。已安装在本机，不需要百炼 Key、Hugging Face 账号，也不需要用户启动终端或服务器。仅显式选择 cloud 才调用原来的云端服务；本地故障不得自动切云端。

用户上传课件和录音并要求整理，就是执行本地转写的指令。不要再问“是否转文字”，不要要求手动改格式、分割、复制路径、启动模型或填写 Key。只在学科、日期或录音先后顺序确实无法判断时补问。不要向用户承诺噪声下绝对准确。

## 自动流程

1. `{"action":"doctor"}` 检查 `local.ready` 与 ffmpeg/ffprobe。Key 未配置不影响本地运行。`ready` 是文件与环境自检，不等于本次识别已成功。
2. 先区分真实上传附件与用户文字中给出的外部本地路径。真实附件直接使用；外部本地文件先用 DSH 文件工具复制到本次工作区 source/（若工具拦截，按其审批机制处理），再把字节一致副本交给 prepare，不能把外部路径误认为会话附件。路径不清时调用 `{"action":"attachments"}` 列出本会话已上传录音，按用户顺序选择这节课的两份。插件只接受当前会话真实附件或工作区文件，不会授权整个主目录。附件会自动经 DSH 附件服务校验并复制到工作区，无需用户手工操作。
3. **本地 prepare 不传 vocabulary/context**，先启动录音，术语表在课件提取后留作校订依据。实测 100 个及 30 个术语均曾被模型复述并造成对齐越界；缩短词表不是可靠修复。调用：

```json
{"action":"prepare","engine":"local","files":["第一份附件路径","第二份附件路径"]}
```

本地版自动解码为 16 kHz WAV，普通手机双声道默认混合并记录参数，原件保留；特殊独立麦克风录音可选 `channel:"0"` 或 `"1"`。不强降噪、不删静音、不剪时间线。单份最多 120 分钟，同堂总计最多 180 分钟。

4. 保存返回的 `job_id`，调用 `{"action":"start","job_id":"返回值"}` **一次**。它在后台加载模型，按顺序处理这一堂课全部录音；不需要 cloud_authorized。另一个本地任务在运行时自动排队，不并发挤占 GPU。关闭网页不等于停止后台转写；Mac 关机/进程终止后可恢复。
5. 用 `{"action":"poll","job_id":"返回值"}` 或 status 查询本地进度，处理其他材料时每 30–60 秒一次；空闲时用 `scripts/wait_audio.py` 每次最多等待 60 秒。等待时继续课件核对，不让用户负责查进度。`progress` 含完成分段数；任一文件 DONE 即可 read 并融合，只有全部完成才称完整融合。INTERRUPTED 后可再次 start，复用已验证分段；FAILED 先读 error，确定性对齐错误不要盲目 start。旧词表任务省略词表重新 prepare 一次，保留旧缓存作证据；无词表仍失败就披露缺口。
6. 每份完整分页读取：`{"action":"read","job_id":"返回值","audio_id":"audio1","offset":0,"limit":60}`；按 next_offset 继续到 null，audio2 DONE 后也完整读取。每批立即写课堂增量与覆盖记录，不只读第一页。本地 worker 完成时写 local-state.json 和 *.local.raw.json；poll 才生成 *.transcript.md/json，故不能只等待 transcript 文件来决定何时 poll。`*.transcript.json` 中的 gaps 是无识别文字区间，不能一概当静音。
7. 按知识点融合普通讲解与例子，名词解释、老师重点/强调、补充和纠错等学习栏目保留知识原文及内部顺序。名词解释与老师强调的外层按 note-style.md 统一为普通引用 `> 名词解释：……`、`> 老师强调：……`，其他栏目保持原有结构。出处和录音时间仅保存在内部映射，不进入成稿。完成 `alignment.md`、`audio-coverage.md` 和 `corrections.md`，再执行原有 plan/commit 入库流程。原音频复制件路径记录在 job.json 的 source，可作为原件指纹输入，派生 audio1.wav 不可替代原件。

## 时间来源与质量边界

- 两份各约 45 分钟录音独立从零计时，不拼成虚假的连续课堂时钟。
- 本地按低能量边界切成不超过 25 秒的连续分段，逐段保存原始识别结果及原音频偏移，段间不删时间。边界疑难内容可截取跨边界片段复核；不要误称采用了重叠切段去重。
- 使用本地对齐模型定位各段发言范围；内部转写保留 ASR 原始标点与数字，不用对齐器的去标点词串重建原文；普通成稿可忠实整理，受保护栏目原文不改。时间是自动对齐结果，不是人工听核。
- **当前本地版没有自动说话人分离**，speaker_id 为 null。老师/学生身份只能基于有依据的上下文；不确定就标“发言者未确认”。不能把长段中的全部话自动算成老师讲解。
- 原始 `*.raw.json`、`*.local.raw.json` 和逐段缓存不修改。修订写在 corrections.md。特别检查数字、单位、否定、考试范围、作业和重叠人声。识别正确性需用户真实录音抽查，不以模型体积或工具成功作保证。
- 疑难处可 `clip` 截取最多 120 秒的原声供回听，也可对片段另行本地识别。片段时间戳加上 offset_ms；不同结果不得让文字模型凭常识投票。DSH 文字模型不能声称听过。
- 转写缺失就说明课堂融合未完成，不把纯 PPT 版当成完整融合版。完整读取后仍有无法核实内容，按实际缺口标注并披露。

## 可选云端（默认不走）

只有用户明确要求云端复核时，prepare 使用 `engine:"cloud"`，北京地域，模型 `qwen-audio-3.0-asr-flash-filetrans`。需要用户本机配置 DASHSCOPE_API_KEY。仅云端可传最多 100 个、不超过 60 字的术语；先去重并检查数量，不把本地禁用词表的规则误套到云端。每个文件分别 start，并传 `cloud_authorized:true`；poll 查询云端结果。费用另计，不自动充值。已有云端 job 仍按原引擎恢复，不因默认值改变而迁移。

SUBMIT_UNKNOWN 代表可能已经产生云端任务但未收到确认，禁止自动重发，防止重复计费。用户改选本地后，不能把旧的云端授权当作自动回退许可。

## 仅在工具缺失时

新插件需要重启 DSH 进程（仅刷新网页无效）；技能正文改动通常可立即重新加载。必要时 DSH 可自行在课程工作区用同一引擎 CLI 兜底，不要求用户执行：

```sh
node "$HOME/.dsh/vendor/dsh-classroom-audio/bin/audio.mjs" '{"action":"doctor"}'
```

CLI 不持有会话附件身份；外部附件要由 DSH 在限定路径授权后复制进工作区。不得打印凭据文件、绕过文件沙箱或扩大到整个主目录。

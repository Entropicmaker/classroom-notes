# 在线学习视频素材交接

用于online-course-materials生成的lecture-materials/1.0包。**本视频分支的审阅由上游visual-review.md与review-next/save/detail流程控制；不套用照片/PPT/PDF的每张原图逐页摘抄、再次逐张读图要求。** 其他照片/PPTX/独立录音流程保持原要求。

1. 读取manifest/source，沿用vault.json及note-style的课程、日期、命名；日期依据与本P范围写清。下载标题/发布日期不能当上课日期。最终文件名/H1为YY.M.D 本节具体内容，例如26.9.27 沉积岩的形成，课程名只用于文件夹。
2. 已转写材料直接完整分页读segments和coverage；waiting_asr由上游推进，不重prepare录音或把切块WAV当原件。无文字区间不能自动判静音；媒体探测确无音轨时只整理可见内容。
3. 使用上游review-next返回的全幅时间画面组进行实际审阅，每批review-save立即保存；640px预览用于场景/过程/可辨内容，小字、公式、图例、新标注和疑点经review-detail精读原图。图相似不证明重复；动画/演示/实拍按开始、变化、转折、结果保留过程及时间对应；不以一张静帧替代整个过程。混合视频按片段判断，不固定板书ROI。
4. 口述按完整讲解组织，不虚构PPT；科普不强加教师/考试标签。不把候选号当原PPT页码，不猜speaker。alignment只给时间候选；来源时间只留在内部审阅/对齐记录，成稿不显示出处与时间线。按主题融合所有实质文字、解释链、例子/推导、条件和视觉关系；赘述/装饰可合并或排除，记录依据，不逐帧写流水账。名词解释与有依据的老师强调遵守 note-style.md，使用普通引用 `> 名词解释：……`、`> 老师强调：……`；知识原文与内部顺序完整保留，不折叠，其他受保护栏目保留原结构。
5. 草稿、校订、覆盖和审阅在JOB/draft，所需图在草稿旁assets，使用标准相对Markdown链接。遵守上游细读/裁切/补图额度，复用核对结果，不自动分派子代理或修改推理档位。真实未核实内容与采样密集区间明确披露，不能将previewed写成原图逐张精读。最终复核对照已保存证据，只重看有实际疑点的图。
6. 完成成稿与缺口复核后，通过上游review-export/review/import-note，来源集固定manifest.source_files，不直接运行vault_import.py绕过视频登记。用户要求整理入库已授权，只有实际路径权限限制/课程歧义才需处理。保护个人改动和同名旧笔记。

图片由现有入库程序复制到Vault；字幕、转写、候选截图/事件索引、来源指纹和审阅记录留在job。成功入库后上游自动删除网站视频、音轨和ASR媒体缓存，清理失败继续cleanup；本地原件和失败任务保留。保留链接和素材包路径，不能声明清理后的媒体仍可本地播放或原PPT已恢复。

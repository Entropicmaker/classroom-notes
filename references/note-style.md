# 笔记风格与原文保护

优先达到“课件完整、课堂讲解有证据、易阅读、方便自己补充”。不因篇幅、重复感或主观判断“不重要”而删除知识，不扩展成知识研究。以下逐字保留规则针对课件；录音讲解允许按 `audio-review.md` 忠实去赘词和组织，不要求把所有口头禅抄入笔记。

- 一级标题与“日期+学科”文件名一致。开头简短注明课程日期/整理日期及依据、材料来源，随后用二级标题保留课件章节和逻辑。目录中未展开的章节保留目录信息并注明未展开，不自行补写。
- **默认完整摘录原文**：保留所有可辨认的知识文字，包括标题中的信息、定义、分类、别名、括号说明、条件、例外、否定、因果、实例、习题及已给出的答案、数字、单位、公式和图表可读内容。图片中的文字与普通文字同等对待。不得以“主要包括”“等”替代原文枚举。
- 只允许不改变表述和逻辑的排版整理：去除多余空格、修复换行、加标题和列表、规范可等价表达的 Markdown/LaTeX。拆句分点保留全部原词、连接关系与限定范围。不能同义改写、润色、缩句或用总结替换原文。跨页整合须保留各页原文和来源对应，不揉成缩写段落。
- 完全相同且上下文一致的内容才可合并，并列出全部来源；同主题、相似表述或仅部分重叠不算完全重复。不同版本的条件、数字或结论分别保留，不自行统一。纯装饰、无知识信息的页码/校徽可不转写；其排除理由记在内部覆盖清单。
- 明确定义按原句摘录，只处理换行/多余空格。定义原句中的条件、例子、括号说明不得挪走；独立的补充说明放块外：

```markdown
> [!note] 名词解释｜术语
> 完整原句（包括原句内的限定与括号内容）。
```

- 不凭常识添加、更正公式或补齐缺失条件。疑似错误/矛盾用简短 `[!warning] 待核对`，保留课件表述及疑点。无法辨认写明具体来源和区域，不猜字、不默默跳过。用户要求核验时，新增核验结论与课件原文分开并附来源；默认不联网。
- 表格保留全部行列、表头层级、单位、注释与对象对应，过宽可拆表但不能丢信息。不要为精简而用概述替代表格，不把普通段落强行转表。
- 年份、数量、百分比和普通范围直接写；公式/上下标/电荷等使用 `$...$`，保留原符号、正负号、上下标和单位。无法可靠等价转写时保留局部原图并注明疑点，不能只输出猜测的公式。
- 关键结构、晶形、地图、过程等图示保留原图或包含完整标注的页面/照片；不能只保留丢失叠加文字、箭头的底图。图上可读标签、图例、数值和关系同时转写；不为原图未给出的符号补定义，不加入个人推论。
- 普通清晰文字照片可以仅转写；关键图示、无法辨认或易失真的内容附原图便于核对。正文中“附了图片”不能代替对可读知识内容的摘录。
- 图片用简短图名并注明来源。来源格式为“照片 003（原文件名），右下角”或“课件文件名，第 X 张”，每个对应段落/图表或小节注明；合并内容列出全部来源。幻灯片序号与印刷页码分清，不用宽泛页码范围掩盖对应关系。
- 引导词及列表首术语可加粗，标题不额外加粗，不整段加粗。少嵌套，避免强套模板。不生成额外知识问答、记忆卡、刷题、个人理解或附属报告；课件本身已有的题目照录，不代答。
- 标签少量且明确，保留用户原有斜体小记及其未确认状态。完整性缺口在对应位置标记，必要时正文开头简短提示“部分摘录：照片 X 的……无法辨认”。

## 有课堂录音时

以现有课件章节为骨架，在每个知识点后按需要插入老师的解释、推导、实例、适用条件、易错点及更正；只出现有证据的栏目，不给每节机械套完整模板。课件没有覆盖的课堂知识单列“课堂补充”，不硬配某页。开头可用简短重点导航帮助复习，但正文的完整课件和实质课堂增量都要保留。

- `课堂讲解（整理）`：允许去除“嗯、那个”等无意义赘词和合并纯口头重复；保留逻辑链、条件、例子、问答中老师的澄清。不能靠常识补足老师未说的推导。
- `老师强调`：须有明确强调表述及上下文；普通复述不升级为强调，强调不自动等于考试重点。“不考”“了解即可”等反向范围必须保留。
- `老师补充/更正`：与课件原文分开。老师明确更正时说明更正对象和时间；只是转写与课件不同则先标“待核对”，不擅自裁决。
- `课堂提问`：区分学生提问与老师答复，保留有教学价值的互动；身份不明使用“发言者未确认”，不能把猜测或学生回答变成老师结论。
- 来源精确到 `录音 A（原文件名）00:18:32–00:19:10`；没有可靠时间戳时使用转写段落编号并注明。整理后的句子不加引号冒充逐字原话；尚未听核的引文须标“转写待听核”。

呈现示例（仅格式，不是可填入笔记的内容）：

```markdown
### 知识点名称
课件的完整原文……（课件 A，第 12 张）

> [!tip] 老师强调
> 忠实整理的强调事项及适用范围……
> 来源：录音 A 00:18:32–00:19:10；对应课件 A，第 12 张。

**课堂讲解（整理）**：解释过程与例子……（录音 A 00:19:10–00:21:05）
```

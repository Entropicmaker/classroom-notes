# 课堂笔记入库

## 目标与边界

将课件与可选的课堂录音整理成忠实、方便直接阅读与复习的 Obsidian 带图课堂笔记。课件知识完整整理，普通正文保留完整知识链，只合并纯重复；名词解释与老师强调按 note-style.md 使用普通引用，完整知识原文与内部顺序保留，仅去掉出处和录音时间。定义、条件、公式、数据和实质解释不得遗漏。提供录音或转写时，把老师解释“为什么、怎么用、易错在哪里”的讲解融入对应知识点，并突出有证据的强调、补充、纠错及作业要求；不要仅把转写附在 PPT 摘录后面。课堂讲解可去口头赘词并忠实整理，具体规则见 [音频转写与课堂融合](references/audio-review.md)。缺失或听不清的内容明确标记，不补造。

纸笔笔记、个人理解由用户后续加入，不索取或代写。不要顺带重做旧笔记、更新课程导航、移动已有文件或修改 Obsidian 设置。首次配置保存在 `references/vault.json`；只有路径失效或课程不确定才补问，不重复扫描整个磁盘。没有写入权限时按当前环境权限机制申请限定路径写入，不得假装已入库。

成稿与内部摘录分开：逐页核对、来源映射和时间覆盖用于内部复核。内容忠实性、受保护栏目、阅读分层与图表知识整理统一遵守 [笔记风格](references/note-style.md)，复核也包括数字数量级及小结与正文的概念边界。

## 每次执行

1. 读取配置和 [笔记风格](references/note-style.md)。用户指定学科优先，否则依据材料标题和配置别名匹配现有课程；地质学/地貌学等歧义不能猜。按下文确定日期和标题。
2. 清点课件、照片、录音及用户提供的转写，保持输入顺序，并确定哪些属于同一节课。对本次完整来源集合调用 `scripts/vault_import.py lookup --course ... --source ...`。完整集合已导入则告知位置并保护个人修改，明确重做才另建版本。同时检查对应课件是否已有笔记：新增录音不是重复材料，但不能因此覆盖原笔记。仅提供课件时继续原流程；提供音频或转写时必读 [音频转写与课堂融合](references/audio-review.md)，先检查实际转写能力。
3. 在当前任务的 `work/` 下暂存原始材料引用、必要图片、逐页摘录、带时间戳转写、覆盖清单和草稿。课件逐页编号，录音逐文件编号并记录时长；二者分别检查覆盖，不能只选择“重要页”或只转写开头。音频未提供时，不生成或推测课堂讲解。
4. **手机照片（主要输入）**：遵循 [照片与逐页核对](references/source-review.md)，实际查看每一张照片，逐张完整摘录文字、表格、公式和图示信息。OCR 仅可辅助，不能替代看图。不得先摘要再凭摘要生成笔记。
5. **PPTX（次要输入）**：首选 `scripts/extract_pptx.py` 提取文字、表格、图片与位置，读取 `source.md`。它不是完整性证明：脚本不进行图片识别，也不完整处理备注、SmartArt、独立图表数据、公式对象等。按当前可用的演示文稿技能及运行环境要求渲染并逐页查看，与提取文字互补；另检查有无有内容的演讲者备注，有则归入对应页并标为备注。不把全部 XML 或图片一次塞入上下文，分批完成全部页。旧式 PPT 先用可用工具可靠转换并核对页数；转换或渲染受阻要披露，不能称全部页面已核对。其他课程文档同样按实际页或内容单元完整检查。
6. **录音/转写（有则执行）**：依 `audio-review.md` 完成带时间戳的转写、说话人归属、关键片段复核，以及录音片段与课件知识点的对应。原始转写与校订分开保存；转写服务、模型及校订依据可追溯。无法转写时如实保留音频待处理状态，仍可完成课件部分，不得宣称录音已融合。
7. 按笔记风格生成暂存 `.md`，一级标题与文件名一致，章节主题放二级标题。有录音时，按知识点融合普通讲解与例子，保留老师重点/强调和更正栏目，名词解释与老师强调按 note-style.md 使用普通引用格式；内部保存来源依据。正文不显示出处、录音时间线、日期依据或处理说明；可用一句简短主线帮助定位。配图用 `![图名](assets/安全文件名.png)`，从原件复制到草稿旁的 `assets/`；入库脚本转换为相对于目标笔记的链接。所有嵌入图片都必须实际查看。
8. **入库前双来源复核**：以原始照片/渲染页和逐页摘录对照成稿，完成覆盖清单；定义、条件、否定、例外、数字、单位、公式、表格行列与图示关系逐项检查。有音频时，再核对其全部时间区间、知识增量的去向、说话人身份以及每条强调/考试要求的原句证据。发现遗漏就补齐，改义就恢复。未完成复核须继续；确实无法辨认或处理的来源位置、缺失范围和原因记内部覆盖清单；成稿在相关知识点简短提示实际疑点，保留必要原图。课件与录音分别报告完整性，不能用课件已完成掩盖录音未处理。检查完运行 `plan`，确认路径和冲突后运行 `commit`。整理入库已授权这次入库，除实际权限限制或课程歧义外不再索取批准。
9. 简短报告课程、笔记名称和可用文件/Obsidian 链接；有录音时同时说明融合范围及待听核片段。覆盖清单留在任务工作目录，不当作学习正文或额外交付；不能隐藏影响完整性的疑点。不承诺绝对零遗漏或固定耗时。

## 日期与命名

- 默认文件名和一级标题统一为 `YY.M.D 本节主题`，例如 `26.9.27 沉积岩的形成`；年份用两位，月日不补零，日期与主题之间一个空格。主题依据本节实际材料提取，优先该节标题；多主题用简洁并列标题，不使用课程名、整门课名、下载标题中的系列/学校/Raw标签代替。课程名仅用于文件夹归属。用户明确指定其他文件名时优先，脚本传 `--custom-title`。
- 日期优先级：用户明确给出的上课日期 → 用户说明/可靠来源能确定的课程日期（照片可用原始拍摄日期）→ 用户当前时区的处理日期。文件复制/修改时间、PPT 内引用年份、模板日期不能充当上课日期。日期依据仅记内部工作记录；文件名和一级标题保留日期，正文不展示日期选择说明。
- 一批照片日期不一致时，若可确认属于不同上课日，按日期及学科分开生成；属于同一节课的多次拍摄、跨午夜或日期冲突无法确定时，不擅自拆课，使用用户指定日期，必要时仅补问日期归属。缺失拍摄元数据本身不需要补问，按上述回退规则处理。
- 同日同学科的不同批次不自动追加或覆盖已有笔记；使用 `YY.M.D 本节主题（02）.md`，继续冲突则递增。重复材料仍先执行 lookup，不用改名绕过重复检查。明确重做用 `YY.M.D 本节主题（重整版）.md`，冲突则在重整版内加序号，并使用 `--new-version`。
- 图片和来源编号用稳定安全文件名，不强行把每张图片改成同一个“日期+学科”。内部草稿、覆盖清单和导入记录不作为最终课堂笔记。

## 固定目录与保护规则

- 笔记：`学习万年历/03 课程/<现有课程>/<日期 本节主题>.md`。
- 图片：`学习万年历/09 附件/课程/<课程>/<标题-内容指纹>/`。脚本负责链接及同名处理，不修改全库附件设置。
- 导入记录：课程文件夹内 `.classroom-imports/`，仅存来源指纹、目标和图片摘要，避免相同资料重复导入，不作学习正文。指纹只能识别文件，不证明内容完整。
- 同名笔记存在时拒绝覆盖；不得通过删除重建规避。脚本的 `plan/commit` 只验证文件与入库条件，不验证摘录完整性，不能替代逐页复核。
- 用户要求补充已有笔记时，先读目标全文、识别用户小记和改动，仅补指定内容。脚本只支持新建；需修改时在工作区保留原文副本，以定点编辑保留既有内容，新增图片沿用附件规则并遵守实际权限。只有用户明确要求时才批量重命名旧笔记，并同步链接与导入记录。
- 同一课件后来补录音时，先定位已有笔记。明确要求“补充这篇”则按上一条定点补充；未指定修改既有文件时新建“YY.M.D 本节主题（课堂融合版）”，保留旧笔记并关联，冲突加序号。来源集合增加会改变指纹，不能把 lookup 无匹配解释为从未导入课件。
- 入库脚本支持任意原始文件作为 `--source` 指纹，但只自动复制图片，不复制录音、字幕或转写。音频来源记录原文件名、可用持久路径和时间；不伪造音频嵌入、自动跳转或已归档状态，不把临时工作路径当永久来源。
- 脚本没有课程自动创建、旧文件清理或全库批量改写功能。新课程需用户明确指定后创建。

## 脚本用法

两个脚本使用 Python 3 标准库；它们不提供语音识别。原音频需要当前环境的可用音频工具或独立 ASR 服务，只有转写时可直接融合并标明未经原音频听核。以实际技能目录为以下路径基准：

```sh
python3 scripts/extract_pptx.py '/path/to/source.pptx' --out '/path/to/work/extracted'
python3 scripts/vault_import.py lookup --course '地质学' --source '/path/to/photo01.jpg' --source '/path/to/photo02.jpg'
python3 scripts/vault_import.py plan --course '地质学' --title '26.9.13 矿物的基本特征与分类' --note '/path/to/work/draft.md' --source '/path/to/photo01.jpg' --source '/path/to/photo02.jpg'
python3 scripts/vault_import.py commit --course '地质学' --title '26.9.13 矿物的基本特征与分类' --note '/path/to/work/draft.md' --source '/path/to/photo01.jpg' --source '/path/to/photo02.jpg'
# 有录音时，lookup/plan/commit 均传入课件和录音原件：
python3 scripts/vault_import.py lookup --course '地质学' --source '/path/to/slides.pptx' --source '/path/to/lecture.m4a'
```

多份材料重复传 `--source`，保持输入顺序。拆成不同日期/学科的笔记时，每份仅传其对应来源。`--config` 仅用于用户明确选择其他库或临时目录测试，不能绕过目标范围。lookup/plan 只读；commit 才写入。

# 照片处理与逐页覆盖核对

## 输入清点

为每张照片建立稳定编号（照片 001、002……），记录原文件名；遵循用户指定顺序，否则按明确连续编号或输入顺序，不凭内容猜顺序。拼图中的多个课件画面分区编号。同页不同照片仍逐张查看：清晰版本相互补足，记录合并来源，不把新增文字或不同标注误当重复。

内部 `coverage.md` 每个来源至少一行：来源编号/原文件名、主题与可见区域、摘录文件或段落、成稿对应位置、图片去向、重复合并/纯装饰排除理由、未辨认区域、初读和复核状态。需要时按表格、公式、图示等拆为多行。此清单只用于工作核对，不要求用户阅读。

提供录音或转写时另按 [音频转写与课堂融合](audio-review.md) 记录时间区间覆盖；不要用“PPT 已核对”代替音频复核。课件来源保持原页码，录音可以跳页、回讲、跨页，同一页可对应多段不连续录音。

## 逐张识读

1. 实际查看每一张照片的全图，确认是否旋转、含多个画面、被遮挡、反光、模糊或边缘截断。原始文件保留；必要时用支持的查看工具放大或分区查看，不能使用生成式修复来还原文字。
2. 按标题、正文、脚注、表格、公式、图示及边缘区域依次读取，写入带来源编号的逐张原文摘录。OCR 如可用，只作初稿，必须回看照片核对。分批处理时持续保存摘录与清单，后续只处理未完成来源，不能因上下文限制放弃尾部照片。
3. 对照原图复核小字、括号、否定词、限定条件、数值、单位、公式上下标、表格对应、图例与箭头方向。内容可见但无法辨认写“[无法辨认：照片 003，表格第 2 行第 3 列]”；边缘截断写明“画面截断，后续内容未拍到”。可辨认部分仍完整摘录。保留包含上下文的原图，不能用省略号无声替代。
4. 来源照片不清但同页其他照片能补足时记录依据；不凭常识、课程经验或相邻页猜补。需再次查看时局部放大；确实缺失且影响理解的内容可请用户补拍，同时完成其余可处理部分。

## 成稿核对与放行

逐个来源重看原图/幻灯片渲染页，与逐页摘录和成稿对应；逐项确认每段知识、每个表格行列、公式、图示标注都已保留。确认所有输入编号都在清单中，不能仅统计总页数或依赖文件指纹。检查重复合并有明确去向，排除项确为无知识内容。

- **完整核对**：全部来源已查看并复核；可辨认知识内容均有成稿去向；没有已知未说明的遗漏或改义。可说明“已逐张核对可辨认内容”，仍不承诺绝对无误。
- **部分摘录**：来源有无法辨认、拍摄截断或工具无法读取的部分，逐处注明，附可用原图/来源，告知具体缺口；其余来源必须完成核对后才能入库。不能把未查看的照片当成无内容，也不能因为附了原图就标作完整转写。
- **尚未完成**：只是未读完或尚未复核，继续处理，不以“部分摘录”掩盖未完成的工作。

覆盖清单是执行检查记录，不是自动语义证明；现有提取和入库脚本不判断是否漏字或改义。

成稿呈现按 note-style.md：编号、原文件名、页码和识读/覆盖记录仅内部保存。内部逐张摘录可保留原文，普通学习正文允许忠实总结与融合；名词解释统一用普通引用 `> 名词解释：……`，老师重点/教师重点/教师强调等同类栏目统一用 `> 老师强调：……`；知识原文、术语/主题和内部段落、列表及先后顺序保留，仅清除出处与录音时间。两类栏目直接显示，不使用提示框或折叠；其他受保护学习栏目保持原有名称与结构。

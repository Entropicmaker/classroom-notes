# 通用视频视觉审阅

本流程用于连续视频候选帧，不改变独立照片、原PPT/PDF的逐页要求。全幅低清RGB扫描同时检查形状/布局与颜色变化，只是候选生成器，不是语义完整性证明；不屏蔽固定区域、不用感知哈希直接删除近似画面。重复字节合并仍保留全部occurrences_ms。

## 顺序审阅

`review-plan --job JOB` 生成审阅计划到draft/visual-review。每组最多8张640px全幅预览、时间跨度不超过120秒；同一原图在不同时间再次出现仍保留序列位置，不能把A→B→A折成A→B。2000张是本地截图额度，不是需要2000次模型调用。

`review-next --job JOB` 只给下一组/细读疑点、相邻文本和已核对ID。先用read_image看它返回的image，不另读旧的24张小联系表。返回preview_pending时一次写下面的检查点到draft/checkpoint.json，再 `review-save --file FILE --job JOB`：

```json
{
  "batch_id": "batch-0000",
  "sequence_note": "0–12秒显示循环起点、粒子移动和汇聚结果；与该段旁白相符。",
  "visuals": [
    {"id": "visual-000000", "scene": "animation", "review_status": "previewed", "note": "起点与流向已辨认；写入‘循环过程’并保留序列图。"},
    {"id": "visual-000001", "scene": "diagram", "review_status": "needs_detail", "note": "图例颜色含义与小字单位尚需核实。"}
  ]
}
```

ID必须真实且包含该组所有不同ID。scene可为ppt/board/demo/animation/diagram/footage/talking_head/mixed/nonteaching/unknown。previewed表示缩略图已审阅，viewed表示原图已请求并实际核对；不是同一等级。needs_detail会阻止最终导出；确实无法识读用unreadable，工具/细读额度限制未解决用unresolved，正文披露具体缺口。所有状态都需内容去向或排除依据，不能只有“已看”。

明确同内容时duplicate需duplicate_of指向已有previewed/viewed的ID，并说明无新增知识的依据。板书新笔画、屏幕新输出、动画转折、图例变化或同页新标注不可按相似外观合并。同图再次出现时复用内容记录，但检查本段上下文与时序。无法分类用unknown并披露，不猜无内容。

## 针对性精读与停止条件

`review-detail --job JOB --id ID --purpose '具体内容疑点'`返回原图路径，read_image一次后review-save更新该ID（无需batch_id）。还不清且确实影响知识时，`review-detail ... --box x1,y1,x2,y2`裁切原图像素区域。先原图再裁切，每图最多2个不同裁切；同一请求返回相同路径，不重复收费计数，已核对则直接复用。禁止反复调6倍/10倍、阈值化、相邻图hash来辨认不影响知识的采集编号、播放器UI或装饰。

默认精读数=min(180,max(24,ceil(视频分钟×1.2)))，裁切数=min(60,max(12,ceil(分钟÷2)))，补图数=min(48,max(8,ceil(分钟÷3)))。默认无子代理、不自动改推理档位。额度是细读调度边界，不是遗漏内容的许可：先完整审阅所有预览与转写，将额度留给实质疑点；额度用尽先复用已有证据，无法核实的具体内容标unresolved，完成其余内容，交付时说明。不能跳过尾部、伪填viewed或自动扩大额度。

需要动画中间态或遮挡前后证据才 `snapshot --time 秒 --purpose '需核实的转折/文字' --job JOB`。它计入补图额度、撤销旧最终review；计划自动刷新，保留未变ID的审阅与计数，但新增时序必须核对。优先在同一知识段一次选好所需时刻，不因无意义页码逐秒试探。

## 不同片段的判断标准

- 静态课件/板书/图解：保留全部可辨认知识，重点精读新文字、数字、公式、条件、箭头、图例与增量，重复外观仅比较内容后合并。
- 动画/软件演示：顺序核对起始条件、操作/运动、转折和结果；至少覆盖支撑结论的中间态。动态图形有文字同样精读。旁白相似不能证明画面无新增信息。
- 实拍/实验/科普：观察对象、时空尺度、对比、操作顺序和观察结果，区分视频明确解释与自己推测。装饰镜头可排除，需记录判断依据。
- 口述/访谈：完整整理讲解，画面用于人物/情境/新资料判断；纯人物动作不逐帧转录，出现资料/演示立即按对应片段处理。
- 混合内容：逐段变更标准，不给整片套一种类型。不设固定板书ROI，也不裁掉屏幕角落、字幕条或其他可能有知识的区域。

## 采样密集区间与成稿

scan.json列出sampling_windows：全片事件超过本地截图额度时，首尾及全片各时间窗优先保留切换/稳定状态，不仅保留开头；events.jsonl列出全部检测事件及是否出图。**这不是完整逐帧保存，不能将未出图事件称为重复或已审阅。** 在预览中定位密集区间，结合转写和必要补图检查运动过程、短暂文字等。通过review-save提交sampling_reviews，逐一列同范围的sequence_reviewed+具体时序证据，或unresolved+内容疑点；序列已核对仍不证明每个微小状态均已看到。不能以字幕覆盖代替视觉过程。

所有预览组、需精读项、转写/无文字区间及成稿均完成后，缺口JSON数组另存文件（无缺口用[]）。review-export需--note-reviewed；它从检查点生成最终review，带方法、计数和SHA。导入器核对检查点/草稿一致性；未知、不可辨认、未核实的图或密集区间需在相应知识点简短注明疑点，并在文末用一两句“部分摘录”写清受影响的内容范围；不列出处、时间索引和处理统计。脚本只证明文件/结构/额度一致，不能证明代理真的看了图或语义完整。

保留一份主题工作稿，每批只追加知识增量和简洁去向；不生成逐帧全文摘录、反复复制同一旁白或将847张候选表塞进学习正文。最终复核复用已核对证据，只重看有实际疑点的图。

成稿按 `classroom-notes/references/note-style.md` 复核：图表独有知识有可读正文去向，数字与已有证据一致，小结保留概念边界，受保护栏目原句与内部顺序完整。抽查无缺口不能推断全部无遗漏；复用已保存证据，仅对未解决疑点局部核对，不为成稿审查重跑整段ASR或重新逐张读图。

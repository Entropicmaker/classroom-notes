# 访问、恢复与边界

支持B站普通BV、av、b23短链和多P。番剧、直播、付费课、收藏/订阅自动发现不属当前版本。下载优先yt-dlp；提取失败时使用已验证的公开DASH兼容路径并选择H.264可解码轨，站点接口仍可能改变。

HTTP412表示站点风控，停止自动重试。401/403/登录需求、下架、权限不足分别报告，不解释为“没有内容”。首次轨迹已完成指定BV的公开DASH下载，但不能保证其他视频均可访问；每个新会话仍需实际验证图片通道。用户明确提供有权使用的Netscape cookies文件时可prepare --cookies；不自动读取浏览器账号或要求粘贴Cookie值。Cookie不进入素材包；状态输出隐藏路径，错误隐藏URL和密钥字段。可用用户有权提供的本地视频继续：

```sh
python3 SCRIPT prepare --local-video '/课程/video.mp4' --subtitle '/课程/subtitle.srt' --course '学科' --asr
```

字幕可选，支持SRT/VTT/B站JSON/segments JSON。优先平台字幕并保留类型；非AI标识不代表人工核实。WBI字幕接口拒绝时记录失败并尝试本地ASR，不反复模拟浏览器或破解签名。

status查看阶段与数量，start复用已完成媒体/画面阶段。未完成全帧扫描会重跑，失败保留文件与错误。412等授权材料/环境变化再恢复。cancel终止本技能采集进程组，不误杀独立音频任务，须说明ASR可能继续运行。

asr每次推进已有插件的一块，顺序执行防止GPU并发。INTERRUPTED可续跑；FAILED/对齐错误保留证据，不盲目start。整轨切块后复核边界漏句。原始模型结果在插件job下，原始工具分页结果另存bundle，不改写模型输出冒充原话。

批次上限防止误抓整门课。大量运动超出本地截图额度时，按全片时间窗分配候选，保留全部检测事件索引和未出图区间，不截断尾部、不自动增加max-images或放大采样间隔。通过review-next检查时序和密集区间；真实视觉疑点用有界补图核实。数值变化不等于知识变化，场景和内容由实际视觉审阅判断。模型超时先查review检查点，默认顺序、无子代理，只续做未保存部分，不整段重开大量并发。

本地音频插件还需写入其既有 ~/.dsh/local-asr/gpu.lock；若沙箱拒绝该已配置路径，按当前工具的路径审批机制取得访问后建立一次新音频任务，保留原失败证据，不视作模型对齐错误。不扩大工作区或改全局权限。

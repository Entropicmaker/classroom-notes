# 学习视频整理（DSH）

支持BV/av、多P和本地视频。沿用当前主模型，不改变模型或推理档位、不另调远程文字/视觉API；无字幕复用已有本地ASR。技能工具返回的Base directory下 `scripts/course_materials.py` 为 `SCRIPT`，统一 `python3 SCRIPT ...`。普通整理不修改插件源码、编写临时采集/OCR脚本或扫描历史会话。

## 采集与恢复

1. 集中读取 `classroom-notes` 的vault.json、note-style.md和本技能storage.json，按标题/内容匹配现有课程。新课程或归属确有歧义才补问。素材固定在桌面“学习ppt”的课程/课次文件夹内。日期未提供用用户时区整理日，依据只记内部记录，不把发布日期当上课日期。
2. `prepare --url '链接' --course '课程' --asr`；本地用 `--local-video`，可提供 `--subtitle`。默认P1，仅明确要求才 `--pages all` 或指定范围。默认20P、240分钟、4GiB，2000张本地全幅候选截图。already_imported直接返回已有笔记，保护个人修改。仅采集素材的请求不执行入库/清理。
3. `start --job JOB`，约30–60秒 `status`，同时读已完成材料；waiting_asr执行 `asr --job JOB`推进已有任务，不反复重转写。脚本先启本地ASR，再扫描画面。下载选择可解码轨；失败按 [访问与恢复](references/access.md) 处理。首次/依赖变化才doctor，第一张审阅预览验证图像通道，同时计入审阅。
4. `validate` 后，`read --kind transcript --limit 200` 分页读到next_offset=null；完整读coverage，核对无文字区间，不据波形/字幕空白判无讲解。无音轨已由媒体探测确认时只整理视觉内容，不虚构旁白。

## 通用视觉审阅与内容组织

读取 [视觉审阅](references/visual-review.md)，使用 `review-plan`、`review-next`、`review-save`；需要原图/裁切才 `review-detail`。**视频画面按时间序列审阅，不套用课堂照片“每张单独全文摘抄/再次逐张读图”的流程。** 全幅检测不固定教学ROI，不根据标题把全片归为板书；按片段判断静态内容、动画/演示过程、实拍、口述或混合。

预览是真实视觉审阅，但不能把640px缩略图称为原图精读。预览可辨认的画面关系/过程可直接记录；小字、公式、表格、新标注或不确定关系必须精读。候选相似只提示比较，不能自动宣称无内容。动画保留起始、变化、关键转折、结果和旁白对应；不能用最终静帧替代过程、把每个动作逐帧抄成流水账或解释视频没给的机制。

图像通道不可用时记录限制，按现有课堂OCR兜底读取可用文字；图示/过程未核实必须标部分摘录，不反复测试通道或伪填previewed/viewed。

默认由当前代理顺序处理，**不自动创建子代理**。只有用户明确要求委派才最多2个并发、禁止递归；保持用户模型/档位，一批完成保存后领取下一批，失败先复用已保存记录，仅重试未完成的一批一次，不整段补做。调用量由审阅脚本计数，不自动增额或临时改源码规避额度；不得绕开helper另写无限裁切/读图循环。

按知识点融合全部实质文字和视觉信息，保留完整知识链、解释、推导、例子、条件与更正。成稿完整继承 `classroom-notes/references/note-style.md` 的数字核对、概念边界、图表知识整理、阅读分层和栏目保护规则；不以整页截图替代内容。动画/实拍写清证据可见的关系与过程，分清原文、旁白与整理推论。来源时间只记内部记录，alignment只有时间候选。科普不强加“老师强调/考试重点”，板书/演示不虚构PPT页码。只留支撑理解的图或时间序列，装饰背景不需逐字描述。

每批立即保存审阅记录，复用核对结果；只保留一份内容工作稿和简洁映射，不在多份中间文档反复抄写全文。细节额度或工具限制导致的真实疑点写明具体内容/范围；未读完继续完成，不能以“部分摘录”掩盖尚未做的工作。

成稿复核须排除误混入的模型工作话语、思考标记、工具调用与处理日志；课堂本身展示的命令、代码、提示词和推理过程须完整保留，依据来源区分，不能按关键词全局删除。

## 成稿、入库与清理

沿用 `classroom-notes/references/online-materials.md` 的视频分支。草稿、覆盖、校订和审阅在JOB/draft，所需图在草稿旁assets并用标准相对Markdown链接。文件名和H1为 **`YY.M.D 本节具体内容`**，例如 `26.9.27 沉积岩的形成`；月份日期不补零，去掉Raw/学校/系列标签，课程名只用于文件夹。用户明确自定义才传--custom-title。

对照已保存内容摘录/来源图做一次成稿复核；若疑点已解决不机械重新读取所有原图。按 [素材契约](references/material-contract.md) 填缺口，`review-export --note DRAFT --gap-reviews FILE --note-reviewed`，再 `review --file 返回文件`、`import-note --note DRAFT --title 'YY.M.D 具体主题'`，均传--job。修改草稿后重新复核和export。只用包装程序入库登记，保护同名/个人编辑；明确重整用prepare/import-note的--new-version。

成功入库自动删除网站下载视频、音轨、派生WAV及本课次ASR媒体缓存，先写media-archive.json保留身份/指纹。保留笔记需要的图、候选截图/事件索引、字幕/转写、草稿/审阅与来源链接。本地原件、未入库/失败任务保留；清理失败继续cleanup，不能口头宣称完成。已清理后不能本地播放、补图或重转写；需要时重新获取新版本。简短交付笔记链接、实际范围、具体疑点与释放空间，不承诺逐帧语义完整。
